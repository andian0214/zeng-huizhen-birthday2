# 曾惠珍女士六十寿宴邀请函｜微信最终版

## 直接发布
1. 将 index.html 上传到支持 HTTPS 的网站空间。
2. 如果需要背景音乐，把 music.mp3 放在 index.html 同目录。
3. 将生成的 HTTPS 链接发送到微信群或微信好友。

## 微信分享标题和缩略图
普通 HTTPS 页面可以直接分享链接。
如果希望在微信中自定义：
- 分享标题
- 分享描述
- 分享缩略图
- 朋友圈标题

需要正式接入微信 JS-SDK，并由服务器生成 signature。

注意：微信 AppSecret 绝不能放在 index.html 前端代码里。

## 一键导航
当前版本使用高德地图关键词搜索：
“新化县幸福之家酒店”

## 推荐部署
可上传到：
- 自己的网站服务器
- 腾讯云对象存储 + CDN
- 阿里云 OSS + CDN
- GitHub Pages（适合测试）

正式发微信建议使用自己的 HTTPS 域名。
